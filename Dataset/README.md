# Dataset

The dataset used to train and validate this project is restricted and is not distributed as open source. This repository contains no raw clinical images, annotations, patient records, or dataset archive.

The final classification checkpoint stores eight abbreviated labels: `w1.n`, `w2.dys`, `w3.ca`, `w4.ev`, `w5.ec`, `w6.ero`, `w7.d`, and `w8.s`. These labels are preserved exactly; they are not expanded without an authoritative class dictionary.

The final detection checkpoint stores these labels exactly as supplied: `Dysplaisa`, `SCC`, `Bleeding`, `Inflamed`, `Aisle`, `Cardia`, `Foreign body`, `Equipment`, `Word`, `Bubble`, and `Reflective`.

Access can be granted only by the dataset owner or originating institution under applicable ethics, consent, privacy, and license conditions. Researchers should contact the project maintainers with an approved purpose and data-handling plan.
